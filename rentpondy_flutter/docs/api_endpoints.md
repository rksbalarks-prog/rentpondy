# API endpoint inventory (source of truth)

Every endpoint the **existing React user app** calls, extracted from
`Rent_Pondy User/src/{Components,pages}` — both the `${process.env.REACT_APP_API_URL}/...`
form and the `${API}/...` alias form.

The Flutter port **must reuse these exact endpoints** — the PPC backend and
MongoDB are unchanged. Base URL: `https://rentpondy.com/PPC/PPC`, and every
request carries `?base=PY|CH`.

Note: RentPondy-specific routes are usually the `-rent` suffixed variants.
